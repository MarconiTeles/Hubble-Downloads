# Hubble para macOS

[Baixar a versão mais recente](https://github.com/MarconiTeles/Hubble-Downloads/releases/latest/download/Hubble-1.0.1.dmg)

O Hubble 1.0.1 requer macOS 13 ou mais recente. O aplicativo é assinado com Developer ID e notarizado pela Apple.

## Atualizações

A partir da versão 1.0.1, use **Hubble > Buscar Atualizações…** ou o mesmo comando no ícone da barra de menus. O aplicativo também verifica automaticamente quando há uma nova versão disponível.

Quem ainda usa a versão 1.0.0 precisa instalar a 1.0.1 manualmente uma única vez pelo link acima.
